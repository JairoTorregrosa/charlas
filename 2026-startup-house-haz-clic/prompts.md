# Los 4 prompts de «Haz clic con IA»

Cópialos, cambia lo que está entre [corchetes] y díctalos con el micrófono.

**1 · Prende el micrófono. Háblale natural.**

```markdown
# Quién soy
Soy [rol]. Sé [esto]. No sé [esto otro].

# Qué quiero
[resultado] para [fecha], para [quién].

# Regla
No supongas nada. Si te falta algo, pregúntame.
```

**2 · Tú hablas con Opus. Opus habla con las máquinas.**

```markdown
# Tarea
[lo que necesito]

Divídela en partes y repártelas.
Tráeme solo lo que yo decido.
```

**3 · Más ambición. No preguntes si puede.**

```markdown
# Meta
Quiero [algo grande] para [fecha].

¿Qué necesitas de mí para lograrlo?
Accesos, datos, decisiones: pídemelos.
```

**4 · Una sola conversación. Lo escaso es tu atención.**

```markdown
Seguimos en este mismo hilo. Ya sabes quién soy y qué quiero.
```
