Anthropic hace esta distinción: un workflow sigue un camino definido en código. En un agente, el modelo elige el siguiente paso y la tool que necesita. Y con los datos a la mano, revisa su propio resultado.

El agente repite hasta poder responder

mientras no termine:
    respuesta = modelo(contexto)
    si pide una tool:
        contexto += ejecutar(tool)
    si no:
        entregar(respuesta)
Seis líneas. El resto es ingeniería alrededor. Miren quién decide: el modelo. El programa ejecuta la tool, agrega el resultado al contexto y vuelve a preguntar. El script completo, unas 100 líneas, está en el repo de la charla.

Una skill enseña un procedimiento reutilizable

Cuándo usarla, pasos, reglas.

v3 
Objetivo · Reglas · Salida

+ .claude/skills/margen/SKILL.md
  ajustes retroactivos, nómina, ausencias

v3 da cifra, cálculo y causa.

Una skill es un archivo. La escribes hoy y el agente la usa hoy. La carga cuando necesita explicar la causa. Más ejemplos en anthropics/financial-services: skills para limpiar, auditar y entregar hojas de cálculo.

En Claude Code, cada palanca tiene un lugar

  • 1system prompt → CLAUDE.md (contexto del proyecto) · --append-system-prompt
  • 2tools → integradas + MCP
  • 3skills → .claude/skills/<nombre>/SKILL.md
CLAUDE.md entra solo, como contexto del proyecto. MCP agrega tools externas. Cada skill vive en una carpeta con su SKILL.md.

Agent SDK integra el agente en tu producto

Tu aplicación inicia el loop, define sus tools y recibe cada mensaje.

query(prompt, options=ClaudeAgentOptions(
    system_prompt=..., mcp_servers=..., skills="all"))
Es el motor de Claude Code como librería, en Python y TypeScript. Tu aplicación llama a query() y procesa cada mensaje.

Managed Agents opera el runtime por API

Tú configuras system prompt, tools y skills. Anthropic ejecuta las sesiones y el sandbox.

client.beta.agents.create(name=..., model="claude-opus-5",
    system=..., tools=[{"type": "agent_toolset_20260401"}])

toolset: bash, archivos, web, MCP · beta

Esto ya lo vieron en la demo 3. La API recibe las palancas, abre la sesión y opera el sandbox. Está en beta.
