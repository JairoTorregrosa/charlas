# Buscar el próximo vuelo

1. Pide la fecha de hoy con `hoy`. Sin la fecha, "próximo" y "última semana" no significan nada.
2. Busca con `buscar` los correos de aerolíneas de los últimos 7 días.
3. Ignora las promociones y las encuestas: un asunto con precios o con "¿cómo estuvo tu viaje?" no es una reserva.
4. Lee el correo completo con `leer` antes de responder. El asunto no trae ni la hora ni el código.
5. Responde el vuelo futuro más cercano: fecha, hora, ruta y código de reserva. Una sola frase.
